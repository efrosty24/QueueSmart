# QueueSmart

Monorepo with a React frontend and a Python FastAPI backend, containerized with Docker.

## Structure

```
QueueSmart/
├── frontend/   # React + TypeScript (Vite)
└── backend/    # FastAPI (coming soon)
```

## Getting started

### Frontend

Requires Node.js 20+.

```bash
cd frontend
npm install
npm run dev      # http://localhost:5173
```

Other scripts: `npm run build`, `npm run preview`, `npm run lint`.

### Backend

Not yet added.

### Docker

A root-level Docker setup (Dockerfile / Compose) will be added so the whole stack can be built and run as containers.
